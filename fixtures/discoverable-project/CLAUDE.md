# Discoverable project

## Repository structure

```
discoverable-project/
├── src/
│   ├── api/
│   │   ├── routes.ts
│   │   └── handlers.ts
│   ├── models/
│   │   └── user.ts
│   └── components/
│       └── Button.tsx
├── scripts/
│   └── build.sh
└── docs/
    └── setup.md
```

## Build

Run `./scripts/build.sh` to build. The legacy client lived in `src/legacy/api.ts`
and setup notes are in docs/setup.md. Use feat/branch-names and `owner/repo` freely.
